## 2. 硬性规则

1. **禁 Mock 兜底、禁编数据**：页面数据必须来自真实端点；没数据就显示空态/缺失，不许造默认值或演示假数。
2. **不动业务逻辑与接口契约**：只改视觉与交互。若必须动接口，同步改后端测试并跑全量。
3. **每项完成的定义**：build + vitest 过 → commit/push → 服务器更新 → 浏览器验证 → §5 勾选 + 写进度日志。
4. 提交信息中文；不把密码/Token/.env 写进提交。

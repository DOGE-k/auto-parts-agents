## 初次注册字段

- `aic` 为空表示尚未由平台分配；申请初次注册前不需要自行编造 AIC。
- `active: false` 与当前 `lastModifiedTime` 用于满足初次申请字段结构。正式 AIC、激活状态与修改时间由注册服务在相应流程中维护；不是要求用户先获得身份才注册。
- `protocolVersion: "02.02"` 是目标协议描述；不代表当前部署已完成严格证书身份绑定。
- `streaming`、`notification` 为 `false`，消息队列为空；未将项目自己的 SSE 页面接口声明为标准 AIP STREAM。
- JSON 能解析和通过结构校验，不代表线上审核通过，也不代表服务已可调用。具体待办见 `manifest.json`。
